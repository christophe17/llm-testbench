file; it is read when the phase starts (protocol: `CLAUDE.md` §3). The "weeks"
are units of relative effort, not deadlines.

## Testbench datasets

Verified on 2026-08-26 (`docs/datasets-verification-2026-08-26.md`, ADR 001): NQ removed,
τ-bench replaced by **tau2-bench**, BIRD via **Mini-Dev**. Each loader arrives with the phase
that needs it.

| Use | Datasets | What the dataset provides | Phase |
|---|---|---|---|
| Retrieval | **BEIR** (SciFact, NFCorpus, FiQA) | corpus + queries + relevance judgments | 0 (SciFact), 2, 3 |
| Embedding models | **MTEB** | standardized comparison protocol | 1 |
| Multi-hop | **HotpotQA**, **MuSiQue**, 2WikiMultihopQA | questions + evidence passages | 2, 3 |
| Unanswerable questions / refusal | **SQuAD 2.0** | explicit "no answer" label | 2 |
| Chunking on **raw documents** | **QASPER** | whole documents, not pre-split passages | 1, 3 |
| Text-to-SQL | **Spider**, **BIRD Mini-Dev** | the databases themselves + reference query; ground truth = execution result | 4 |
| Business API, multi-turn agents | **tau2-bench** | API tools + database + rules + simulated user | 4 |
| Tool calls, fine granularity | **BFCL** | argument accuracy, parallel calls, "call nothing" cases | 4 |
| Tables and numerical reasoning | **HybridQA**, **TAT-QA**, WikiTableQuestions, FinQA | text + table cross-referencing, annotated answers | 4 |
| Time series | **synthetic, generated by us** | ground truth computed by pandas: zero annotation, controlled traps (missing values, time zones, overlaps, revisions of past values) | 4 |
| Images: QA on documents and charts | **DocVQA**, **ChartQA** | annotated questions on scanned documents and charts | 4 |
| Images: field-by-field extraction | **CORD**, **FUNSD** | each field labeled → per-field accuracy | 4 |
| Agentic prompt injection | **AgentDojo** | tool-equipped environments + injection tasks | 4 |
| Tabular with free text | **fake_job_postings2** (EMSCAD) | classification, published score | 5B |
| Text classification | **Banking77** | 77 intents, published scores | 5B |
| Voice / browser | VoiceBench, WebArena or equivalents | to verify at the start, same protocol | 9, 10 |

**Implementation notes.** Spider and BIRD are in SQLite: conversion to Postgres (sqlglot),
which is real work and a good notebook. BIRD is large and deliberately dirty —
start with a subset. DocVQA and ChartQA involve a multimodal model, hence a
cost: sample. For time series, the generator is part of the deliverable on the
same footing as the application code: versioned, tested, fixed seed.

**Contamination is a subject to address, not to ignore**: these datasets are probably in
the models' training data, so the scores are inflated. Measurement of a contamination signal
and a small "fresh" comparison set (phase 2.5), reapplied in 5B.

## Common thread: the incident stories

The three interview stories of phase 8 come from the construction itself
(regression detected by the evaluation CI, cost drift, miscalibrated judge, quantization that
silently degrades, pipeline that rebuilds everything). They are recorded **as they happen**
in `JOURNAL.md`, under the "Incidents / surprises" heading — never reconstructed after the fact.
